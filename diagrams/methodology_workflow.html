4.1.1  Input
🔑
User Authentication
  • User submits email + password
  • BCrypt.checkpw() verification
  • JWT token issued (HS256)
  • 24-hour expiry set
  • Token returned to client
jose · bcrypt
›
4.1.2  Access Control
🛡️
Role-Based Access Control
  • HTTPBearer extracts JWT
  • jwt.decode validates signature
  • RoleChecker class runs
  • EMPLOYEE / MANAGER / ADMIN
  • HTTP 403 if unauthorized
RoleChecker · Depends()
›
4.1.3  Cache Lookup
⚡
Cache-First Data Access
  • CacheManager.get(key) called
  • Redis HIT → return instantly
  • Redis MISS → query DB
  • Fallback: in-memory cache
  • TTL: 600 seconds (10 min)
Redis · InMemoryCache
›
4.1.4  Data Layer
🗄️
Database Query & Persistence
  • AsyncSession via SQLAlchemy
  • MySQL (local) / SQLite (cloud)
  • ORM models: User, Attendance,
  •   LeaveRequest, Payslip, Training
  • Pydantic schema validation
SQLAlchemy · aiosqlite
›
4.1.5  Processing
⚙️
Business Logic & Workflows
  • Leave: PENDING → APPROVED/REJECTED
  • Payslip: basic + allowances - deductions
  • Attendance hours computation
  • PDF / CSV report generation
  • Manager review + comments
reports.py · payroll.py

🖥️

  • Axios response updates React state

  • Responsive Tailwind layout
